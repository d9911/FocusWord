Простой ридер с показом слов по одному. Вставьте текст, выберите темп и удерживайте выделенную букву в фокусе.

![FocusWord — application preview](docs/images/app.png)

## Чтение

- Скорость 60–1000 слов/мин, меняется и во время чтения.
- Старт, пауза, повтор, переход по словам и прогресс. Пробел — старт/пауза; стрелки — по одному слову.
- Размер шрифта, третья буква или адаптивная опора, дополнительные паузы на пунктуации и длинных словах.
- Английский, испанский и русский; кастомные меню языка и темы, системная тема, адаптивная вёрстка и учёт reduced-motion.
- PWA, favicon и maskable-иконки; файлы приложения доступны офлайн после первой успешной загрузки production-сборки онлайн. Установка зависит от браузера.

## Локальный запуск

Нужны Node.js 24+ и npm. Без framework, сервера приложения, базы данных и Docker.

```sh
make            # установка при необходимости, запуск и открытие браузера
make start      # то же, что make
make init       # установка без запуска
make dev        # проверка зависимостей, запуск и открытие браузера
make check      # TypeScript, тесты и форматирование
make build      # статические HTML, JavaScript, CSS и PWA → dist/
make preview    # локальная проверка сборки
make format     # форматирование Prettier
make screenshot # сборка и снимок docs/images/app.png (локальный Chrome)
```

Лаунчер устанавливает пакеты по lockfile, если зависимости отсутствуют или изменился отпечаток установки. При каждом запуске сверяются версии прямых зависимостей. Первый запуск создаёт отпечаток; следующие используют готовую установку. В PATH нужны Node.js 24+, npm и GNU Make, в том числе на Windows. Скрипт вызывает npm.cmd на Windows и npm на macOS/Linux. Без Make: `npm start` или `npm run dev`. Браузер открывает Vite; без графического окружения откройте напечатанный URL вручную. Работа на Windows локально не проверена.

Для снимка укажите `CHROME_BIN`, если Chrome/Chromium установлен по другому пути. Скрипт использует временный профиль, английский пример и локальный сервер. Для обычной сборки инструменты снимков не нужны.

## Структура

- `src/reader.ts`: воспроизведение и интервалы, без зависимости от DOM.
- `src/main.ts`: управление ридером и отображение.
- `src/ui.ts` / `src/locales.ts`: поведение интерфейса и переводы.
- `src/types/`: общие типы и интерфейсы; подключаются через `import type`.
- `src/pwa.ts` / `scripts/build-pwa.mjs`: установка и генерация офлайн-кеша.
- `public/`: единственная исходная копия логотипа, иконки, манифест и доступная в приложении лицензия.
- `tests/`: Node-тесты воспроизведения, иконок и офлайн-кеша.

Исходники — TypeScript. В `dist/` находятся скомпилированный JavaScript и статические файлы; вручную их не редактируем. Это одно статическое приложение, а не распределённая система.

## Приватность

Текст остаётся во вкладке: приложение не отправляет его на сервер и не сохраняет в localStorage. Аналитики и скриптов слежения нет. Локально сохраняются язык и тема; service worker кеширует файлы приложения, а не текст. Хостинг может вести журналы обращений. Внешние ссылки открывают другие сайты; README-бейджи загружаются с Shields.io и не входят в приложение.
