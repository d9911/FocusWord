# Контекст FocusWord

Перенесено из чата «Логотип и README FocusWord» от 3 октября 2026 года.

## Решения пользователя

Создать простой веб-ридер: одно слово за раз, выделенная опорная буква остаётся в одной точке, слово сдвигается вокруг неё. Вставка текста, настройка скорости, пауза, возврат, размер шрифта, прогресс и дополнительные задержки. Без озвучки, AI, Docker и прикладного сервера. TypeScript компилируется в JavaScript, есть Makefile и единое форматирование Prettier.

Рабочее название, согласованное в исходном чате, — FocusWord. В последующей речи прозвучало «Focus Work»; для реализации сохранено FocusWord. Название не проверялось на юридическую уникальность. Существующие авторские поля package.json, LICENSE, настройки Prettier и PNG-логотип сохранены. Подготовлена отдельная SVG-иконка в той же концепции W и направляющих.

Незавершённая фраза «HTML, CSS мы не используем, потому что…» не задаёт подтверждённого технического запрета. В этой реализации выбраны минимальные HTML/CSS и vanilla TypeScript, без framework. Vite обслуживает только разработку и сборку; результат — статические файлы.

## Анализ примера

На [странице SpeedReadPro](https://speedreadpro.ru/player), в разделе «Возможности плеера», перечислены скорость, пауза/перемотка, шрифт, цвета, выравнивание, групповой показ, выделение **третьей буквы** и направляющие на неё. Проверен текст страницы; интерактивное поведение, фактическую геометрию и неподвижность буквы **я не могу подтвердить**: сам чужой плеер не запускался.

Фиксированная третья буква и выбор буквы по длине слова — разные варианты. FocusWord предоставляет оба режима и собственное центрирование опоры; цвета/семейства шрифта, групповой показ, библиотека и сохранение позиции в базовую версию не входят. Маркетинговые обещания примера не перенесены.

## Исследования и границы утверждений

В исходном чате была приведена [статья ScienceDirect с идентификатором S0747563214007663](https://www.sciencedirect.com/science/article/abs/pii/S0747563214007663) как источник о Spritz и ограничениях понимания. При переносе содержимое по этой ссылке инструментом не получено; точные выводы этой статьи **я не могу подтвердить**. Ссылка сохранена для дальнейшей проверки, а не как проверенное доказательство.

Доступный первичный источник — [abstract Ricciardi et al., «Speed reading using Spritz has a cost: limits when reading a short text», 2020, DOI 10.1504/IJHFE.2020.109594](https://www.inderscience.com/info/inarticle.php?artid=109594). Авторы сравнивали понимание короткого текста при традиционном чтении и Spritz; abstract сообщает о трудностях понимания при увеличении темпа в условиях этого эксперимента. Это не проверка FocusWord и не универсальная оценка любого читателя. Здесь проверен abstract, не полный текст исследования.

Продукт не обещает повысить скорость, понимание или запоминание. Пользователь может регулировать темп, приостанавливать показ и возвращаться к тексту.

## Границы работы

Только локальная реализация и проверки. Git commit, ветки, теги, push, PR, releases, изменение remote и деплой не выполняются. Денис прямо указал: LICENSE имеет приоритет. Его условия и авторство сохранены без изменений, package.json ссылается на этот файл вместо стандартной SPDX-метки.
