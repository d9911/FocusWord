# Проверка базовой версии

Локально, 3 октября 2026 года. Node.js 24.11.0, npm 11.16.0.

- `npm ci --offline --cache /private/tmp/focusword-npm-cache` — exit 0: установка из lockfile и ранее загруженного кэша. Пользовательский запуск — `make init` (`npm ci`).
- `make check` — exit 0: строгая проверка TypeScript, тесты и Prettier.
- Встроенный Node test runner: 5 тестов, все прошли. Проверены Unicode/пунктуация, рассчитанные интервалы, полная выдержка последнего слова, повтор, отмена таймера при паузе/перемотке/замене текста, пустой и однословный текст, смена скорости. Источник: `tests/reader.test.mjs`.
- `make build` — exit 0: Vite создал `dist/index.html`, CSS/JavaScript, favicon и LICENSE.
- `git diff --check` — exit 0.
- Контрольные SHA-256 до/после совпали для исходных LICENSE, FocusWord.png и .prettierrc. LICENSE, public/LICENSE и dist/LICENSE побайтно совпали по SHA-256.

В браузере на локальном Vite проверены ввод ««Привет,» мир!», переход на следующее слово, возврат к началу, стрелка вправо, пробел, завершение, повтор и пауза. Для показанного «мир!» центр опоры и центр области чтения равнялись 632.5 CSS px по DOM-измерению.

При viewport 375 px проверен длинный токен. Первая проверка обнаружила обрезку из-за измерения ширины grid-колонки вместо текста; после исправления измерения весь токен помещался внутри области (текст от 173.734375 до 323.84375 CSS px при границах области 16 и 344). Отклонение центра опоры от центра области — около 0.004 CSS px (округление геометрии браузером), горизонтального переполнения страницы нет. Цена размещения очень длинного токена — уменьшенный шрифт. Размеры получены через `getBoundingClientRect`, `Range.getBoundingClientRect` и computed style, а не оценены по изображению.

Проверки не доказывают повышение скорости чтения или понимания. Проверка чужого интерактивного плеера, деплой и проверка всех браузеров не выполнялись.

## Дополнение: языки, темы, PWA

После расширения интерфейса `make check` и `make build` повторно завершились с exit 0. Итог: **8 тестов, 8 прошли** — пять проверок ридера, две проверки манифеста/PNG/ICO и регрессия service worker. Размеры PNG сверяются с IHDR, ICO проверяется по записям и смещениям. Тест worker использует сгенерированный скрипт, временный каталог и недоступную сеть: CSS/JS с `Vary: Origin` должны читаться из кеша, LICENSE — оставаться отдельным файлом, POST/чужой scope — не перехватываться, чужие кеши — не удаляться.

Браузерная проверка:

- RU / EN / ES: тексты интерфейса, пример, состояния и aria-label переключаются. В Chrome выбор испанского языка через ↑/↓ и Enter не заменил русский текст и сохранил позицию `2 / 25`. После reload выбранные Español и тёмная тема сохранились.
- Светлая/тёмная темы переключались. Начальный системный режим в текущем окружении выбрал тёмную тему. Изменение самой настройки ОС во время работы отдельно не проверялось.
- Во время чтения изменение числа до 600 и нажатие «+» дало синхронные 610 в поле и ползунке без остановки. После последней правки отдельно проверены 333 в обоих элементах и нормализация пустого поля в 300 при blur.
- Chrome viewport 375 px: `innerWidth=375`, горизонтальное переполнение отсутствует. При показе длинного токена отклонение центра опоры равно 0 CSS px; токен уменьшается до доступной ширины. Хедер, язык и тема помещаются с переносом на вторую строку.
- Для production-сборки Chrome показал кнопку «Установить FocusWord». Само приложение в ОС не устанавливалось.
- Первый offline-прогон выявил реальный дефект: HTML кешировался, но CSS/JS не сопоставлялись из-за `Vary: Origin` у Vite preview. После исправления `ignoreVary` **только для известных статических файлов** и отдельной регрессии повторная проверка прошла.
- Проверка offline выполнена на localhost:5175: worker завершил установку (`data-offline-ready=true`), preview-сервер остановлен, `curl` вернул exit 7 (соединение отсутствует). После reload Chrome загрузил стили и работающий ридер, пример и переход дали `2 / 25`. LICENSE открылся из кеша с исходными условиями. После этих действий изменения касались нормализации поля скорости; она проверена на обновлённом dev-интерфейсе, а финальная сборка и тесты снова прошли.

Повторно подтверждено совпадение SHA-256 исходного LICENSE с public/LICENSE и dist/LICENSE, исходного логотипа с public/FocusWord.png. Настройки .prettierrc не изменились. `git diff --check` завершился с exit 0. Новые runtime-зависимости не добавлялись.

Фактическая установка на iOS/Android, все браузеры, HTTPS-деплой и изменение системного reduced-motion в ходе чтения не проверялись. CSS учитывает `prefers-reduced-motion`. Публикация и Git mutations не выполнялись.
