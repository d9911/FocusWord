# PWA и интерфейс FocusWord

## Интерфейс

Хедер содержит исходный PNG-логотип, кастомный dropdown English / Español / Русский и выбор темы «Системная / Светлая / Тёмная». Начальный язык определяется языком браузера (для остальных языков — английский). Начальная тема определяется `prefers-color-scheme`; в системном режиме смена настройки ОС/браузера применяется без перезагрузки. Явный выбор языка и темы сохраняется в localStorage под ключами `focusword:language` и `focusword:theme`; если хранилище недоступно, переключение продолжает работать в текущей вкладке.

Переведены подписи, кнопки, инструкции, aria-label, placeholder, заголовок и описание страницы, состояния плеера. Смена языка не заменяет введённый текст и не сбрасывает позицию. Пример подставляется на выбранном языке только по отдельному нажатию.

Dropdown открывается мышью, Enter или пробелом. Tab перемещается по языкам, ↑/↓ переключают фокус между вариантами, Escape закрывает список и возвращает фокус. Клик снаружи закрывает его. Читательские shortcuts не перехватываются в dropdown и полях ввода.

Скорость 60–1000 слов/мин изменяется целым числом или ползунком; кнопки −/+ изменяют её с шагом 10. Во время чтения новое значение применяется без паузы и сброса позиции, текущий интервал начинается заново. Некорректное или пустое число нормализуется при выходе из поля.

Блоки появляются с небольшой перспективой при прокрутке. CSS оформляет scrollbar; верхний индикатор прокрутки имеет переливающийся градиент. `prefers-reduced-motion` отключает движение. Сами слова не получают декоративных анимаций. Отрисовка нативного scrollbar зависит от браузера и настроек ОС.

Данные автора в футере взяты из package.json: Denis Gutsuliak, d9911.org, Telegram и admin@d9911.org. Промоблок ведёт на собственный сайт автора; сторонняя рекламная сеть, аналитика и выдуманные рекламодатели не подключены.

## Манифест и иконки

`public/manifest.webmanifest` относится к FocusWord, а не Timepost Files из примера. `id`, `start_url`, `scope` и ссылки на иконки относительные: `./`. Приложение может быть размещено в корне или подпапке. Статический манифест имеет описание на английском; язык самого интерфейса переключается отдельно.

В `public/icons/` находятся PNG 16, 32, 48, 72, 96, 128, 144, 152, 180, 192, 256, 384, 512 и 1024 px. Это набор размеров из присланного образца, а не утверждение, что все обязательны. Дополнительно есть maskable 512 px: знак уменьшен до 72% SVG-холста на сплошном фоне, чтобы ключевые элементы оставались внутри безопасной области. SVG/favicon, ICO с 16/32/48 и apple-touch-icon 180 подключены в HTML.

Иконки растеризованы из нового `public/favicon.svg`, исходный `FocusWord.png` не редактировался. Готовые PNG хранятся в проекте, поэтому Sharp для `make init`, `make dev` и `make build` не нужен. Для повторного экспорта изменённого SVG можно запустить `node scripts/generate-icons.mjs /абсолютный/путь/к/entry-файлу/sharp`; это отдельный необязательный инструмент подготовки изображений.

## Сборка и offline

`make build` создаёт обычную статическую сборку Vite, копирует текущий LICENSE и генерирует `dist/sw.js` через `scripts/build-pwa.mjs`. Service worker регистрируется только в production-сборке; `make dev` не кешируется.

При установке worker кеширует список локальных статических файлов сборки. Текст пользователя не записывается в кеш и по-прежнему исчезает при перезагрузке. Навигация на основной экран получает HTML из той же версии кеша, что и JS/CSS. LICENSE и изображения отдаются как отдельные файлы. Для списка известных статических файлов кеш игнорирует `Vary`: иначе `Vary: Origin` от preview-сервера мешает сопоставлять precache и запросы модульных JS/CSS. Эта политика применяется только к локальным файлам сборки, не к динамическим ответам. Чужие ресурсы, почта, Telegram и сайт автора не кешируются.

Новая сборка имеет новый хеш кеша; ожидающий worker активируется после закрытия вкладок старой версии. Обновление не перезагружает чтение принудительно. Очистка удаляет только кеши FocusWord в **этом scope**, не данные других приложений.

Работа без сети возможна после успешного первого посещения собранной версии и установки worker. Для проверки используйте `make build` и `make preview`. На хостинге нужен HTTPS; localhost подходит для разработки. Основание: [MDN — secure contexts](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Secure_Contexts).

Кнопка установки показывается, если браузер предоставляет `beforeinstallprompt`. В других браузерах доступны инструкции для установки через меню. Наличие кнопки и правила установки зависят от браузера; установка в каждом браузере не обещается. Основание: [MDN — Making PWAs installable](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable), [MDN — manifest icons](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference/icons).

Манифест, scope и заголовки HTTPS должны быть проверены ещё раз после фактического размещения. Деплой в этой задаче не выполняется. Условия LICENSE имеют приоритет и сохранены дословно.
